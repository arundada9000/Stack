Feedback

Found a bug, have a feature idea, or just want to say hello? Every message goes directly to the developer. I read and reply to all of them.

How to Report a Bug

To help me fix issues quickly, please include the following when you report a bug:

  • Browser and version - Which browser are you using? (Chrome, Firefox, Safari, Edge, etc.)
  • Device and OS - Desktop, tablet, or phone? What operating system?
  • Steps to reproduce - What did you click or type right before the problem happened?
  • Expected vs actual behavior - What did you expect to happen, and what happened instead?
  • Screenshot or screen recording - If possible, a visual makes the bug much easier to track down.

How to Request a Feature

I am always looking for ways to improve EasyStack. When suggesting a feature, let me know:

  • Which page or tool - Is this for the basic visualizer, the advanced tool, the call stack visualizer, or something else?
  • What behavior you want - Describe the feature in your own words. What should it do?
  • Why it helps - A sentence on how this would make learning stacks easier for you or others.
