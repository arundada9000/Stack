# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-09-01

### Added

- 22 guide pages covering operations, implementations in 5 languages, the call stack, stack memory, monotonic stacks, recursion, DFS, browser and OS stacks, and interview problems
- Advanced stack visualizer tool with keyboard shortcuts and a step log
- Call stack frame visualizer tool
- Complexity analyzer tool with SVG charts
- 404 and offline fallback pages
- iOS HIG design system (hig.css and hig.js) with light and dark themes, Inter and JetBrains Mono fonts
- PWA support with a web app manifest, service worker, and offline fallback
- SEO, AEO, and GEO metadata: JSON-LD `Article`, `SoftwareApplication`, `HowTo`, `FAQPage`, and `BreadcrumbList` on every page
- Clean URL rewrites via `_redirects`
- Professional repository files: LICENSE, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, CHANGELOG, issue and PR templates, and architecture docs

### Changed

- `index.html` gained glass navigation, a footer link grid, keyboard shortcuts, and `WebSite` JSON-LD
- Contact and privacy pages were redesigned with navigation and breadcrumbs

## [1.0.0] - 2025-01-01

### Added

- Initial release: stack visualizer with push, pop, peek, clear, and display operations, with code examples in C, C++, Java, Python, and JavaScript
